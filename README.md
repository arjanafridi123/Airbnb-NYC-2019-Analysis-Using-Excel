# Airbnb-NYC-2019-Analysis-Using-Excel

# 🏠 Airbnb NYC 2019 Excel Dashboard

# 📌 Overview

An interactive Excel dashboard developed to analyze Airbnb listings across New York City using the Airbnb NYC 2019 dataset. The project transforms raw listing data into meaningful business insights through data cleaning, pivot tables, charts, and interactive dashboard visualizations.

The dashboard helps analyze:

* Listing distribution across boroughs
* Room type performance
* Price trends and comparisons
* Host activity and listing concentration
* Availability patterns
* Customer review insights
* Key business performance metrics

---

# 📊 Dashboard Features

* Interactive Excel Dashboard
* Pivot Tables & Pivot Charts
* KPI Summary
* Borough-wise Analysis
* Room Type Analysis
* Price Analysis
* Host Performance Analysis
* Availability Analysis
* Interactive Slicers for filtering
