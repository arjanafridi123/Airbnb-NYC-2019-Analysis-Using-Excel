# 🏠 Airbnb NYC 2019 Data Analysis Using Microsoft Excel

# 📌 Overview

This project presents an exploratory data analysis (EDA) of the Airbnb NYC 2019 dataset using **Microsoft Excel**. The analysis leverages Pivot Tables to explore pricing patterns, room type distribution, neighborhood performance, host activity, and customer review trends across New York City.

The objective is to transform raw Airbnb listing data into meaningful business insights that support market analysis and data-driven decision-making.

---

# 📊 Business Questions Answered

* Which neighborhoods in New York City have the highest average Airbnb listing prices?
* How do room types compare in terms of pricing across different neighborhood groups?
* What is the average minimum stay required for each room type?
* How do monthly reviews vary across room types and neighborhood groups?
* Who are the top 10 hosts based on reviews per month?
* How does room availability differ across room types and neighborhood groups?
